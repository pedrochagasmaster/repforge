RIR logging

Easy ≈ 3 reps left in the tank (RIR 3) · Hard ≈ 1 left (RIR 1) · Max ≈ nothing left (RIR 0).

Start with these defaults. Change them when you need a different load step or RIR target.

Minimum jump increment is always in kg regardless of display units.

Taurifer counts sets at or below this RIR toward completed hard-set volume. Taurifer saves changes automatically.

Questions

Is it free?

Building your program, logging sessions and getting the next target are free, with no account and no sign-up.

Do I need an app store?

No. Taurifer opens in the browser. To put its icon on your home screen:

iPhone, in Safari

  1. Tap ••• at the right of the address bar, then choose Share.
  2. In the share sheet, tap View More at the end of the actions row.
  3. Choose Add to Home Screen.
  4. Leave Open as Web App on and tap Add.

Android, in Chrome

Open your browser menu and choose Install app or Add to Home Screen.

If you already logged sessions in the browser, you can move that data into the installed app. The transfer only happens if you ask for it, and it expires within an hour.

What is RIR?

RIR is the number of reps you could still complete before failure. RIR 2 means two reps left. If you are new to RIR, estimate whether you could do one or two more.

Can my coach send me a program?

The link isn't encrypted: anyone who gets it can read your program.

Does Taurifer collect any data?

It collects usage data, and that option starts switched on: pseudonymous usage events and screen recordings with all content masked. Logged loads and reps, exercise names, notes, free text, setup links and backups are left out.

Privacy

Your training data stays on this device except when you explicitly create an install transfer.

Program setup links

A setup link carries a program proposal in its #setup= fragment. It is an unencrypted bearer link, so anyone you forward it to can read and use it. For the iOS Home Screen handoff, the temporary repforge_setup_v1 cookie carries that proposal to the static host for up to seven days. It never includes workout logs or program history.

Temporary install transfer

The encrypted logical clone includes your normalized program and workout state, history, archive and provenance, active workout draft, unfinished program setup, UI preferences, analytics consent, and stable telemetry identity. It excludes volatile locks, journals, transaction markers, cookies, permissions, cache state, and provider session state.

The transfer needs a network connection. Cloudflare can handle the request at its global edge before a Durable Object processes and stores it in the EU. Cloudflare briefly sees plaintext while creating and claiming the record. TLS protects transit. This is server-side encryption, not end-to-end encryption.

Taurifer derives AES-256-GCM encryption from the one-time token with HKDF-SHA-256. The service never stores the token or derived key. It stores ciphertext, a keyed token digest, nonce, associated data, and random salt.

Live ciphertext is deleted after the installed app verifies the local import and commits it, or by minute 60. A payload-free tombstone can remain through minute 75. Cloudflare recovery images can retain ciphertext for up to 30 days, but the restored image alone cannot decrypt it after the token and key are gone.

The handoff cookie contains only the opaque token and expiry. The static host receives it with the matching HTML request. Transfer access logs must strip cookies, request bodies, tokens, and full URLs.

Create abuse counters use HMAC-derived IP buckets. They store no raw IP, are not linked to a transfer or token, and last no more than two minutes.

Safari keeps its original local data. After a completed or uncertain transfer it becomes a recovery snapshot. To resume there, you must confirm that future Safari and installed-app changes stay separate and never merge.

The transfer preserves analytics consent, telemetry identity, and UI preferences. It is not an account, cloud backup, or synchronization. The intentional Safari and installed-app copies remain on their devices.

Telemetry and consent

Telemetry is opt-in under the consent policy in Settings. It sends coarse product funnels with a stable anonymous identity, never workout values, exercise names, notes, free text, setup links, transfer tokens, or backup data. You can turn it off at any time.

Export and delete

Use Settings to export a JSON backup before moving or clearing this browser. Delete workout history permanently removes logs and the active draft from local storage while keeping your program and Settings. The separate delete-all action names everything it removes before you confirm.

Limitations

Taurifer has no automatic cloud sync or server backup. Clearing browser storage or losing the device can make data unrecoverable without an export. A setup link is a bearer link, so forwarding it gives the recipient the proposal. Browser and installed-app copies do not merge.
