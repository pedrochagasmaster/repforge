- `about_half` stays `interrupted`; the disabled treatment flag and runtime consumption are the defects (`B01`, `B02`).
- Program-only Import converges on the candidate preview. Full-backup restore remains a distinct explicit restore operation (`B07`, `F11`). The final-review legacy first-run regression reopened `B07`; `20fb1f92` stages it in the common preview and `888f8c2f` advances the shell cache lockstep.
- Shared setup retains ADR 0007 parsing, first-run precedence, cookie handoff, and consent; convergence begins only after that hardened handoff (`F12`). The final-review documentation contradiction is closed by `5bbd05b9`, which aligns ADR 0007, the brand guide, and the program-entry flow with the common preview contract.
- F4 parity must derive its vocabulary and executable family/frequency cases from the adapter and reviewed fixtures; hardcoded pass booleans and duplicate keys are not evidence (`S02`). `58e0c4e3` closes that final-review standards/spec finding.
- Browse can only expose a release catalogue whose facts are declared from the existing closed family/blueprint inventory. This work may not invent a new family, blueprint, or compiler constant (`C21`).
- Screenshot evidence is committed, immutable during comparison, and checked with structural and material perceptual comparisons. The semantic artifact proves user-visible copy and state, while the PNG comparator proves dimensions and material visual changes. The earlier local-pixel detector remains documented as a failed cross-host approach (`S05`, `S06`, `S09`, `S10`, `S17`, `S18`).
- Catalogue capture waits for persisted Resume state, pins locale and UTC, reports bounded semantic diffs, and preserves meaningful domain identifiers while ignoring only generated exercise-row IDs (`S14`, `S19`, `S25`, `S26`).
- Evidence replacement installs the PNG and semantic artifacts before best-effort backup cleanup, and the documented immutable-baseline command copies both artifacts and removes the writable temporary tree through its exit trap (`S20`, `S21`, `S27`).
- Generative Browse journeys and Import visual evidence represent only real handoffs and supported progression ownership (`S22`–`S24`).
- Shared preview facts come from released payload metadata and the compiled set structure. Paired compiler identities round-trip through strict validation without fuzzy aliases, and duration changes when released rest or set inputs change (`P01`, `P02`, `S11`).
- Unsupported progression relations remain explicit incompatibility evidence. Candidate edits and Build drafts preserve that metadata, block activation when needed, and leave the active program unchanged (`P03`–`P06`).
- Recommendation parity fixtures use the approved "program" vocabulary (`S12`).
- Picker focus return recomputes editor readiness and assertively exposes incompatibility (`S13`).
- The PostHog token finding is valid even though the faulty filter predates this PR: the exact pinned SDK drops an event when `before_send` removes `token`, so Plan 048 telemetry is otherwise nonfunctional (`C33`).
- Visual mocks guide composition, while brand and accessibility control CTA color, chrome, shadows, type size, and target geometry (`F07`–`F09`).
- The dependency-free `program-entry.js` boundary is restored. The pure module owns its closed entry vocabulary, the adapter consumes it, the browser loads the pure module first, and regression coverage protects the direction (`ba5736b8`).
- The paired-relation editor focus race is fixed. The editor waits for its rebuilt status node after the picker close transition before moving focus (`083a5c3b`).
- `T06` is unavailable external evidence, not an implementation blocker. Repository compatibility fixtures remain the available evidence, and no real-user corpus is fabricated.
