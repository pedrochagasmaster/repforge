# G · Síntese: polish audit

Baseline: `round-3/acceptance/summary.md` at the freeze (360/360 cells, 0
warnings, 122/122 journeys, 61/61 interaction checks), reproduced in this
session before any change. Shots studied in every one of the eight cells;
findings are cited on the cell where they are worst. Measurements are CSS
px at 100% text unless stated.

The owner's brief in one line: G reads as today's onboarding, tidied up.
Every finding below names the way it makes G feel timid, cramped,
misaligned, generic, noisy or unclear, ranked by how much it does so. The
fix stays inside G's structure and the Q622–Q637 decisions; the role it
lands on is a Plan 058 type/radius/depth role or a Direction D system rule
(`DIRECTION-D-SPEC.md` §3–4), so the review hands off to the Today it will
share a screen language with.
