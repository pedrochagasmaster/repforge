Main-screen candidates

Seven directions redraw the same eleven screens from one lifter's real week 4. A, B and C are the first round. D is built to DIRECTION-D-SPEC.md; E, F and G are candidates built on D that apply the same correctness fixes and system rules in different ways. D to G also draw six extra screens: the set-2 Why, a mixed-strategy day and a first session. In D to G, every target is computed live by progression-engine.js and every shipped word is read from i18n.js. Portuguese is the default; switch to EN to check the second language.

Review page only. It is not loaded by the app, not precached, and does not touch index.html, styles.css, app.js or sw.js. Serve the repository root over HTTP and open docs/design/main-screen-directions/. Arrow keys move between screens; 1 to 7 switch direction. Compare shows every direction on the current screen.
