## Capability composition

Setup codec capabilities supply TextEncoder, TextDecoder, CompressionStream, DecompressionStream, Blob, atob, btoa plus optional document/location defaults for the cookie/fragment helper API. Per-call adapters continue to override document/location. Missing compression still yields the existing compression-unavailable outcome. No browser global registers or dependency fallback remains.

Transfer capabilities supply TextEncoder, TextDecoder, crypto, document, location, navigator, matchMedia, fetch, indexedDB, atob, btoa and `now`. Existing method-level overrides remain available for fault injection and concrete browser policy. No credential value, logical clone or source URL is logged. Contract crypto may be passed per integrity validation as before; its factory's default is explicit.

Interchange cannot import persistence. Its serializers therefore receive validated transport values; application orchestration imports both persistence snapshot policy and format serializers. The small private `json.js` retains the single bounded file parser shared by program/backup consumers and clone fallback used by program serialization. It is not a generic schema framework.

## Focused evidence and limits

The initial new-interface test failed with missing native modules before implementation. After extraction, exact old/new public-module checks pass for setup validation, full v4 encoded bytes, decoding/refused legacy links, fragment handling, envelope parser/validation, canonical hashing, real acknowledged DraftV2 logical capture, profile unknown-field preservation, device preferences and freeform exclusions, deterministic envelope build and context eligibility. Serializer checks assert exact filename/field/column order, custom-alternate closure, parser refusal bounds, quoted/newline CSV bytes and lastExport acknowledgement-before-share, including both single-replica outcomes and total failure.

`test/interchange-protocol-native.mjs` adapts only the retained Node harness's module lookup to native production factories. It runs the unchanged owned assertions/fixtures: client/shared-contract parity 9/9; client fault policy 45/45; full shared-setup v4 protocol (representative complete URL 649 characters). The native contract receives native metrics/compiler/entry/workout rules, so this exercises the new graph. The lookup adapter is temporary verification infrastructure, removed when those retained suites directly import native public interfaces at the coordinated cutover; it is not a production compatibility layer.

Still pending integration acceptance: actual current-reader CSV and full canonical flat-projection wiring, real file-import/reload rejection-without-writes, transfer irreversible local commit/cleanup browser journeys, service's current root-contract import reconciliation, active client/cookie/cross-context behavior in browser, strict typing of the converted scope, release inventory and final-head CI. Do not count module placement, baseline parity or a Node client proof as these browser outcomes. No runtime root source, shell, SW inventory, service implementation, credential, network setting or deployment changed in this extraction.
