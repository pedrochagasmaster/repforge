Atalhos de teclado

Enter
Aprovar, com as edições se houver. Funciona também dentro do campo do nome.
E
Editar o nome em português
Esc
No campo: descartar a edição; de novo: sair do campo
S →
Pular (fica no rascunho)
←
Voltar ao anterior
J K
Descer / subir na fila sem pular
Z
Desfazer a última aprovação
A
Adicionar sinônimo (Enter adiciona, Backspace remove o último)
/
Buscar

No celular, deslize o cartão para a direita para aprovar ou para a esquerda para pular. Cada aprovação grava os dois JSON e regenera exercises.js. Pular não grava nada.
